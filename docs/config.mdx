# Config

The config lives at `config/midnightthoughts.json` and is created on first launch.

<Admonition type="info">
    A full explanation of every parameter is on the matching page in the sidebar. This page is the complete reference: the file as a whole, the in-game config screen, and the rules the mod applies when reading the file.
</Admonition>

---

## In-game config screen

Almost everything in the file can be changed without opening it.

| Loader | How to open |
|---|---|
| Forge, NeoForge | Mods list, select Midnight Thoughts, press **Config** |
| Fabric | Mod Menu, select Midnight Thoughts, press the config button |

The screen is split into five sections:

| Section | What is inside |
|---|---|
| **Sleep overlay** | Overlay, moon, stardust, space objects, slide times, fades, opacity, text and moon size, facts API, custom content, chat and HUD messages |
| **Interface** | Theme, summary style, Well Rested HUD position, hiding the Well Rested HUD and the sleeping players HUD, summary size, season integrations |
| **MVP scoring** | MVP on or off, points, death penalty, MVP buff duration, experience for the day and its limit |
| **Comfort** | Comfort on or off, scan radius, nightmares, sleep block, all eight weights |
| **Server behaviour** | Phantom timer for non-sleepers, vanilla sleep messages |

The screen works from the main menu and in single player. Every option has a tooltip, and sliders show their units: seconds, milliseconds, percent, minutes or blocks. Changes are saved to `midnightthoughts.json` as soon as you leave a section, and in single player they apply to the running world right away.

<Admonition type="note">
    Sliders cover the useful range of each setting, not the full range the file accepts. For example, the comfort weights slider goes from -10 to 10, while the file accepts -100 to 100. If you need an extreme value, write it in the file.
</Admonition>

<Admonition type="warning">
    Well Rested levels are **not** in the config screen. Attributes and effects are lists that do not fit into sliders, so they are edited in the file only. See [Well Rested](./well-rested).
</Admonition>

<Admonition type="tip" title="On a server">
    While you are connected to a server, the config screen shows only one section, **Personal**, with the summary style and the summary size. These two are read from your own file even on a server. Every other setting comes from the server's own config file, so editing your local copy there would change nothing.
</Admonition>

### UI settings

The `ui` section is spread across several features, so here it is in one place:

| Parameter | Default | Description |
|---|---|---|
| `theme` | `"classic"` | Theme of the summary screen and the sleeping players HUD. One of `classic`, `vanilla`, `tech`, `magic`. See [summary screen](./summary-screen) |
| `wellRestedHudPosition` | `"left"` | Where the Rested bar sits on screen. One of `left`, `bar`, `right`. See [Well Rested](./well-rested) |
| `hideWellRestedHud` | `false` | Hides the Rested effect bar with its level and remaining time. See [Well Rested](./well-rested) |
| `hideSleepingPlayersHud` | `false` | Hides the `Sleeping 2/5` plate shown while anyone on the server is asleep. See [for servers](./for-servers) |
| `summaryScale` | `0` | Size of the summary screen. `0` is Auto, `1` to `4` is a fixed size. Personal setting, never taken from the server. See [summary screen](./summary-screen#summary-size) |
| `summaryStyle` | `"picture"` | How the statistics are shown on the summary card, `picture` or `table`. Personal setting, never taken from the server. See [summary screen](./summary-screen#summary-style) |

<Admonition type="note">
    Both `hide` flags are `false` by default, which means everything is shown. Setting one to `true` hides that element for every player on the server.
</Admonition>

<Admonition type="info" title="Removed in 1.6">
    `hideThemeSwitchButton` no longer exists. The gear button on the summary screen was removed, the theme is now picked in the config screen. If the key is still in an old file, it is dropped on the next save.
</Admonition>

## Where the values come from

Most settings are **server-authoritative**. When you join a server, it sends its config to your client, and that copy wins over your local file for the session. This keeps overlay timings, opacity, comfort rules and the theme consistent for everyone.

The only exceptions are `summaryScale` and `summaryStyle`. They are a matter of each player's monitor and taste, so they are always read from the player's own file, also on a server.

<Admonition type="tip">
    In single player your own file is used, and the config screen edits it directly.
</Admonition>

Changing the config on a live server does not require a restart:

```
/midnightthoughts reload config
```

The file is re-read, validated, and pushed to everyone online. If the file got messy and you want to start over, `/midnightthoughts config recreate` backs it up and writes a fresh default one. Full command reference on the [commands](./commands) page.

## Validation

The config is checked every time it is read. Values that make no sense are corrected rather than rejected, and each correction is written to the server log so you can see what happened.

<Tabs>
    <TabItem value="clamped" label="Clamping" default>

        Out-of-range numbers are pulled back to the nearest valid value.

        | Setting | Allowed range |
        |---|---|
        | `minSlideDisplayTimeMs`, `maxSlideDisplayTimeMs` | 500 to 120000 |
        | `fadeInDurationMs`, `fadeOutDurationMs` | 0 to 10000 |
        | `overlayOpacity`, `textOpacity`, `imageOpacity`, `specialSlideChance` | 0.0 to 1.0 |
        | `textScale`, `imageScale` | 0.5 to 1.5 |
        | `summaryScale` | 0 to 4 |
        | `durationMinutes`, `mvpWellRestedDurationMinutes` | 1 to 1440 |
        | `regenBonus` | 0.0 to 1.0 |
        | Attribute `phase1` / `phase2` / `phase3` | -10000 to 10000 |
        | Effect `phase1` / `phase2` / `phase3` | -1 to 255 |
        | `scanRadius` | 0 to 8 |
        | `nightmareThreshold`, `sleepBlockThreshold` | -100 to 100 |
        | Comfort weights | -100 to 100 |
        | `minScoreRequired` | 0 to 1000000 |
        | Other MVP point values | 0 to 100000 |
        | `experiencePerPoint` | 0.0 to 10.0 |
        | `maxExperiencePerSleep` | 0 to 1000000 |

        If `maxSlideDisplayTimeMs` ends up below `minSlideDisplayTimeMs`, it is raised to match.

    </TabItem>
    <TabItem value="invalid" label="Invalid values">

        `"theme"` only accepts `classic`, `vanilla`, `tech` or `magic`. Anything else resets to `classic`.

        `"wellRestedHudPosition"` only accepts `left`, `bar` or `right`. Anything else resets to `left`.

        `"summaryStyle"` only accepts `picture` or `table`. Anything else resets to `picture`.

        An attribute `"operation"` that is not one of the known operations resets to `add_value`.

        An attribute or effect entry without an `id` is dropped. An entry whose `id` does not exist in the game, for example from a mod that is not installed, is kept in the file but skipped in game, with one warning in the log.

        Numbers that are not numbers at all, such as `NaN` or `Infinity`, reset to their defaults instead of being clamped.

        A missing Well Rested level is restored from defaults, so deleting `level3` from the file is a valid way to reset just that one.

    </TabItem>
    <TabItem value="missing" label="Missing keys">

        Any key absent from the file is filled in with its default, and the file is rewritten so you can see and edit it. Values already present are preserved.

        Deleting a key, or a whole section, is therefore a valid way to reset it.

        A Well Rested level without an `attributes` list gets the default list for that level. An empty list `[]` is kept as it is and means "no attribute bonuses".

    </TabItem>
    <TabItem value="broken" label="Broken files">

        If the file cannot be parsed at all, for example because of a stray comma or a truncated write, the mod does **not** crash and does not silently overwrite your work. The damaged file is renamed to `midnightthoughts.json.broken` and a fresh default config is generated.

        <Admonition type="tip">
            Your original is still there under the `.broken` name. Fix the syntax error and rename it back.
        </Admonition>

    </TabItem>
</Tabs>

<Admonition type="warning" title="Updating from 1.5.x">
    The Well Rested levels changed format in 1.6. The old keys (`speedPhase1`, `strengthPhase1`, `hastePhase1`, `attackSpeedPhase1`, `healthBonus` and the rest) are no longer read, and each level gets the new default `attributes` list. `durationMinutes` and `regenBonus` keep your values. If you had tuned your buffs, write your values again in the new format. Everything outside the levels carries over as it was.
</Admonition>

## Safe writing

The config and the statistics file are written atomically: the mod writes to a temporary file and then swaps it into place. A crash or a power cut in the middle of a save leaves the previous version intact instead of a half-written file.

<Admonition type="note">
    Statistics are also kept in memory while the server runs and flushed on player disconnect and on shutdown, rather than re-read from disk on every access.
</Admonition>
