### Network optimization

The transmission of the `WellRested` packet has been improved, slightly reducing network traffic

### New commands

Added support for the `/midnightthoughts reload` command,
which performs a hot reload of the configuration without requiring a server restart

<Admonition type="warning">
    This applies only to the config. A full restart is required when modifying custom achievements or slides
</Admonition>
